IRC-assessed efficacy of abexinostat.  a  Waterfall plot showing the IRC-assessed best percentage change from baseline in lesion size for patients treated with abexinostat in the FAS ( N  = 82).  b  Spider plot tracking IRC-assessed changes in SPD of target lesions from baseline over the treatment period in the FAS ( N  = 82).  c  Swimmer plot displaying IRC-assessed treatment duration and response for each patient receiving abexinostat in the SS ( N  = 90).  d  Forest plot for subgroup analysis of IRC-assessed ORR. The dashed black line at 30% for ORR indicates the null hypothesis of this study, representing the expected ORR if the treatment had no effect. CI, confidence interval; CR, complete response; DCR, disease control rate; FAS, full analysis set; FL, follicular lymphoma; IHC, immunohistochemistry; IRC, independent review center; NE, not evaluable; ORR, objective response rate; PD, progressive disease; PR, partial response; SD, stable disease; SPD, sum of the product of the perpendicular diameters; SS, safety set
